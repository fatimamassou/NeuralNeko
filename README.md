# 🐱💌 NeuralNeko — Daily Box

NeuralNeko is a cute pastel-themed web app where you tap a gift box to reveal **one envelope per day** with a positive message.

Soft vibes, cat energy, and a little daily motivation ✨



## ✨ Features

- 🎁 Tap the box to reveal your daily envelope  
- 💌 One message per day (saved in browser)  
- 🔁 View the same message again anytime that day  
- 📋 Copy message to clipboard  
- 🐾 Kawaii pastel UI with smooth animations  
- 💾 Uses LocalStorage (no backend needed)  



## 🛠️ Built With

- HTML5  
- CSS3 (animations + gradients)  
- Vanilla JavaScript  
- LocalStorage API  



## 🚀 How to Use

1. Open `index.html` in your browser.  
2. Tap the gift box.  
3. Read your message.  
4. Come back tomorrow for a new one ✨  



## 📌 Note

All data is stored locally in your browser.  
No server, no database, just pure frontend magic.
